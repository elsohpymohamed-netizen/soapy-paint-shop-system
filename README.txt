نظام متابعة خط الدهان (Smart MES)
=================================
المتطلبات: Node.js نسخة 22 أو أحدث (بدون تثبيت أي مكتبات).

التشغيل:
  1) على الجهاز/السيرفر:   node server.js
     (اختياري)  BASE_URL=https://اسم-موقعك  PORT=3000  node server.js
  2) أول تشغيل يُنشئ 5 متحكمين (controller1..controller5) بكلمة مرور مختلفة لكل واحد،
     ويكتبها في ملف initial-passwords.txt. وزّعها ثم احذف الملف. سيُطلب تغييرها عند أول دخول.
  3) المتحكم يدخل ويضيف مشرف المحطة: يظهر له رابط + مستخدم + كلمة مرور، ويرسلها عبر زر واتساب.
  4) نسيان كلمة مرور متحكم:   node server.js reset controller3

ملاحظات أمان:
  - BASE_URL هو الرابط الذي سيفتحه الناس على موبايلاتهم (لازم يكون قابل للوصول من الموبايلات).
  - للاستخدام خارج شبكة المصنع استخدم HTTPS (عبر Nginx/Caddy أو خدمة استضافة).
  - البيانات في ملف mes.db: خُذ منه نسخة احتياطية دورية.
